Eden Launderette Management System
Project Description
The Eden Launderette Management System is a software solution designed to digitise and streamline the daily operations of a laundry business. The system aims to replace paper-based processes with an organised, centralised database accessible through both a website and a mobile application.

Key Features
Customer Management: Register customers, manage profiles, maintain contact details and view service history.
Laundry Order Management: Create orders, record clothing items and quantities, select laundry services and calculate estimated costs.
Order Tracking: Track laundry orders from receipt through processing to collection or delivery.
Collection and Delivery: Schedule collections and deliveries, assign delivery personnel and record proof of delivery.
Payment Management: Record payments, generate receipt references and track outstanding balances.
Notifications: Notify customers about order progress, delivery updates and outstanding payments.
Database Design
The project uses a relational database designed to support both the website and mobile application. The Entity Relationship Diagram (ERD) illustrates the database tables, primary keys, foreign keys and relationships. The database design supports data consistency, efficient record management and future system enhancements.

Project Objectives
Reduce reliance on manual, paper-based records.
Improve laundry order tracking and operational efficiency.
Maintain accurate customer, order and payment information.
Improve communication with customers.
Provide a foundation for future digital services, including online payments.
Technologies
Database: Snowflake
Applications: Web and mobile applications
Architecture: Client-server architecture with a shared backend and database.
